## About the Project

This project contains two responsive web components developed using HTML5 and CSS3. The main objective is to practice responsive layouts, CSS Grid, Flexbox, transitions, animations, and mobile-first web design.

## Task 2: Responsive Pricing Cards

### Description
A modern three-tier pricing section consisting of Starter, Pro, and Team plans. The Pro plan is highlighted as the popular choice.

### Features
- Three pricing cards with different plans.
- Monthly and Annual billing toggle design.
- CSS Grid layout for desktop screens.
- Single-column layout for mobile screens.
- Flexbox alignment inside pricing cards.
- Hover lift effect on cards.
- Glowing animation on the featured Pro plan.

### Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- CSS Animations and Transitions

**File Name:** `task2.html`

## Task 3: Music Player & Playlist Shelf

### Description
A dark-themed music player interface displaying an album section and an Up Next playlist with multiple tracks.

### Features
- Dark-mode user interface.
- Album cover with animated spinning vinyl disc.
- Playlist displaying track names and durations.
- Responsive layout using CSS Grid.
- Flexbox alignment for playlist items.
- Hover transition on playlist tracks.
- Mobile-friendly vertical layout.

### Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- CSS Keyframe Animations
- CSS Transitions

**File Name:** `task3.html`

## Responsive Design

Both components follow a mobile-first approach.

- Mobile screens: Components are arranged vertically.
- Desktop screens: Multi-column layouts are applied using CSS Grid.
- Media queries ensure proper adaptation to different screen sizes.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `task2.html` or `task3.html` in a web browser.
4. Resize the browser to test responsive layouts.

## Conclusion

This assignment demonstrates the practical implementation of responsive web design using HTML and CSS. It provides experience in creating modern user interfaces using Grid, Flexbox, media queries, animations, and transitions.
